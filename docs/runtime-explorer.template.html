    04 / 实际事件日志
    执行边界
    • 每次尝试创建独立容器，只挂载当前工作目录；验证器不能访问其他尝试、SQLite 或 Docker socket。
    • 工具以 UID 10001 执行；根文件系统只读、禁网、移除 Linux capabilities，临时目录与 HOME 独立。
    • 当前按 memory_mb / max_parallel 保守划分容器内存；禁止额外 swap，每个工具限制 1 CPU。
    • 发现相反确定证据返回 CONFLICT；超时、错误、不足展开和不支持属性返回 UNKNOWN。
    • 控制容器持有 Docker socket，仅用于本机可信 CLI。页面回放不会调用它。
